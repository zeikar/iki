New optional roles `lash_lower_L` / `lash_lower_R`: an eye's lower lid, its dark line and lashes, drawn over the iris so it covers the iris's bottom edge the way a drawn eye does. It rides its eye's warp grid and folds onto the same crease as the eye white on the blink, so it keeps to the white's lower edge and closes into the seam under the upper lash. A layer set without these roles rigs exactly as before. A layer set that names them needs this release: an earlier `@ikijs/editor` refuses an unknown role.
