Depends on the new `@ikijs/editor`, so `auto_rig_from_layers` rigs with that release's new defaults: a model it rigs from this release turns, nods, rolls, blinks, gazes, opens its mouth, raises its brows, breathes and sways by new amounts. The `style` description now names the new `hairFollow` (1) and `blink` (0.6) defaults, and the tool descriptions no longer cite a Live2D profile. The `.iki` format does not change, and models rigged earlier are untouched until they are rigged again.
